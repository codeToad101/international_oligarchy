1. CORE QUESTION AND HYPOTHESES
-------------------------------

1.1 Question [SLIDES 2]
  Is an oligarch's survival and continued international capture, through
  backlash and collapse, better predicted by its FORMAL POSITION (civil vs.
  ruling) or by its RELATIONAL STRATEGY (standing with host states and
  partnership structure with other oligarchs)? Build a transnational ABM to
  isolate the two.

1.2 Why a model [SLIDES 2]
  - Winters, Oligarchy (2011): a baseline exists for oligarchic emergence
    WITHIN a country.
  - Camba & Epstein (2023): a baseline exists for foreign interaction /
    intervention BETWEEN countries.
  - An ABM is needed because oligarchs and countries must both be modeled
    as heterogeneous and discrete, micro-level tendencies and relationships
    are essential, and real data are limited.

1.3 Model type [SLIDES 3]
  Agent-based dynamic network, primarily intellective (Carley 1999): a
  minimal mechanism for generating and testing hypotheses, not a
  point-prediction or calibrated model.

1.4 Hypotheses [SLIDES 3]
  PRIMARY (P): Oligarchic foreign capture and foreign resource
    mismanagement ("havoc") rise with network embeddedness, with this
    relationship being similar in strength and function between civil and
    ruling oligarchs.
  SECONDARY (S): The chief dynamic change that removes an oligarch from the
    international stage is asset loss -- not a lack of network ties nor the
    type of oligarch.
  Note on labels: comments in the code use legacy labels "H-b" (foreign
  capture / havoc) and "H-c" (exit / survival). Inferred mapping: H-b = P,
  H-c = S. [AGREED; code renamed to P/S in C5]

1.5 Built-in counterbalancing forces
  Backlash, collapse and seizure are built in so that outcomes are
  conditional on parameters rather than baked into the mechanism.

1.6 What "exits" means (operational)
  Exit = removal from the international stage, operationalized in Section 6.3
  as a persistent collapse of ACTIVE capital (offshore excluded). Without an
  exit rule, hypothesis S is not measurable. [AGREED in direction; exact
  rule and thresholds PROPOSED -- see 6.3]


2. GOAL AND SCOPE
-----------------
Target: publication in an undergraduate research journal.

Framing: a minimal, clearly explained mechanism and its conditional
behavior -- NOT a richly calibrated model. Cross-national capture data
barely exist in usable form, so the paper's value comes from structural
plausibility, verification, and sensitivity analysis (Carley 1999;
exploratory SD tradition such as World3), not point prediction. All numeric
parameters are PLACEHOLDERS tuned for structural plausibility, not fitted.

Scope conditions to state in the paper:
  - Prices are STATIC in v1 (Section 4.6, 9). [AGREED]
  - Closed oligarch cohort: no new entrants. [AGREED]
  - Offshore capital is one-way (never reinvested). [IMPLEMENTED]
  - Exit liquidation destroys the 30% fire-sale discount and sends proceeds offshore to the
    exiting oligarch; nothing goes to the state, rivals or population (no GDP /
    wealth-to-population channel). State as a scope condition. [IMPLEMENTED; future work in 9.2]
  - One merged position stock (illiquid and invested capital). [IMPLEMENTED]
  - Symmetric goodwill (directed goodwill parked). [IMPLEMENTED]
  - Oligarch type is FIXED at initialization; no civil-to-ruling
    transition in v1. [AGREED]
  - Backlash is driven by capture load PLUS resource scarcity (the immiseration input); there is no
    wealth-return-to-population channel. [IMPLEMENTED; partial deviation from slide 4 diagram]

Parked (not in v1): adaptive learning (indoctrinate vs. hedge), origin-
wealth asymmetry sweep, passive-vs-ambitious populations, directed goodwill,
deals as discrete events, propaganda.

3.1 Framing literature (all on the slides)

    RULING = direct political power; CIVIL = power through legal/economic
    institutions (property law, courts, lobbying). Model types map directly.
    [SLIDES 5]
  - Tullock (1980) / Hillman & Riley (1989): contest between oligarchs --
    the inherited framework. [SLIDES 5]
  - Hellman (1998), "Winners Take All": alternative framework, inter-
    oligarchic COOPERATION. [SLIDES 5]
  - Heathershaw, Pitcher & Soares de Oliveira (2023): addresses the same gap
    descriptively and calls for more research. [SLIDES 5]
  - Carley (1999), "On Generating Hypotheses Using Computer Simulations":
    methodological framework for limited-data ABMs. [SLIDES 5]
  - Camba & Epstein (2023): baseline for foreign interaction. [SLIDES 2]
  - Sklair (2002): transnational capitalist class; the literature the

3.2 Mechanism sources
  - Tullock (1980); Hillman & Riley (1989) (divisible-prize contest, also
    Hirshleifer 1989): how captured output in each (country, industry) is
    split. share = x^r / sum(x^r), r = tullock_r = 1.
  - Hellman, Jones & Kaufmann (2000): state capture is real but BOUNDED.
    Motivation for kmax = 0.85 (not calibrated to it).
  - Gordon (1954); Schaefer (1954); Clark (1990): harvest depends on effort
    and stock, not a resource-specific efficiency trait. M0 uses the
    exponential-catch form pool * (1 - exp(-q * total_effort)) (Baranov
    origin; Clark 1990), which adds diminishing returns and prevents all-in
    corner solutions.
  - Turchin (2003); Turchin & Nefedov (2009): STRUCTURE of an aggregate
    stress indicator only; no calibrated coefficients imported.
  - McFadden (1974); McKelvey & Palfrey (1995): logit choice for capital
    allocation (logit_lambda).
  - Salton & McGill (1983): cosine similarity (preference overlap; initial
    state-oligarch alignment).
  - Axelrod (1984): MOTIVATION ONLY for goodwill built by repeated joint
    activity. No formula taken.
  - Piketty (2014): r > g logic behind capital accumulation.
  - Post-Soviet 1990s privatization: precedent for collapse as a discrete,
    uneven reallocation event; origin of the modern use of "oligarch."
  - Tilly (1985): protection-racket framing of extraction (comparative
    parallel).
  - Ostrom (1990): common-pool framing for unclaimed assets after collapse
    (DEFERRED).
  - Law (2015): common random numbers.
  - Methodology: Borgonovo et al. (2022) (ABM sensitivity analysis
    protocol); Grimm et al. (2005, pattern-oriented modeling; 2010, ODD);
    Liang & Zeger (1986) (clustered/GEE logistic); Nakagawa & Schielzeth
    (marginal/conditional R2 for mixed models).
  - Existing ABMs to differentiate from: OLIGO (Mason & Sengupta) and the
    Ukrainian oligarchic-economy ABM (arXiv). Neither models cross-border
    capture and capital flight as linked decisions. [verify; neither is in
    the slide reference list]

4. MODEL ARCHITECTURE
---------------------

4.1 Scope [SLIDES 6]
  5 countries x 5 oligarchs per country = 25 oligarchs, FIXED (not sampled),
  so seeds are comparable. [IMPLEMENTED: 5 per country]
  Hybrid ABM / SD stocks: Country and Oligarch are the two core agents; each
  holds its own SD-style stocks and its own behavior methods. Relationships
  are a shared object (Relations) both agent types reference, so both ends
  of a relationship see one value. Cross-agent computation is vectorized
  over stacked views of agent state; agents remain the source of truth.

4.2 AGENT 1: Country (the state)
  Fixed traits:
    baseline_wealth            scales resident oligarchs' starting capital
    institutional_resilience   rho in [0.2,1]; harder capture for everyone,
                               faster backlash decay
    collapse_threshold         theta; backlash level at which hazard is half
                               of h_max
    industry_endowment[i]      specialist/generalist split (2 specialty
                               industries); governs POOL SIZE only, never
                               extraction efficiency
    payoff_profile[i]          endowment x price; "potential payoffs" that
                               initialize goodwill
  State:
    backlash_pressure, recovery_left, collapse_count, industry_output[i],
    industry_capture[i] (captured FRACTION of industry i, all oligarchs),
    domestic_capture (output-weighted captured fraction of the economy)
  Behaviors: produce, full_value, update_resource, update_backlash, hazard, check_collapse
  Resource state [IMPLEMENTED]: resource_health[i], scarcity_pressure, health_prev, abuse_rate (see 4.9).
  DEFERRED (on the class, unused): unclaimed_assets, wealth_returned_to_population

4.3 AGENT 2: Oligarch
  Fixed traits:
    oligarch_type              CIVIL or RULING (static in v1)
    home_country
    industry_preferences[i]    Dirichlet shares summing to 1
    divestment_propensity in [0,1]  flight/divest threshold on perceived B/theta:
                               0.4 + 0.8 * (1 - propensity); higher = earlier flight/divestment
                               (renamed from risk_tolerance in C6; own assumption; drawn independent of
                               type and home; the source of flight heterogeneity)
  State:
    capital                    LIQUID, deployable
    offshore_capital           safe from seizure; small return; one-way
    positions[c][i]            sunk, seizable stock per (country, industry).
                               MERGES industry_investments and illiquid_
                               assets; drives BOTH extraction and the
                               capture contest; this is what collapse seizes
    capture[c][i]              captured fraction of (c,i) output held by this
                               oligarch; decays without continued investment.
                               foreign capture is DERIVED from this
    seized_total               cumulative position value lost to collapse
                               seizure (the seized-assets covariate of S)
    initial_wealth, initial_active (capital + positions at t=0), active, exit_tick, below_count,
                               exit_liq_loss, exit_transfer; cumulative loss accounting seized_total,
                               cum_home_hit, cum_forced_liq, cum_divest, cum_flight (see 6.3).
                               Also: check_exit, leave_stage.
  Behaviors: settle, suffer_collapse, flee_and_divest, net_attractiveness,
    deploy, record_wealth, exited
  Initial domestic influence: each oligarch starts with init_home_frac of
  capital placed at home (by preference x home payoff), and capture starts
  at the contest-implied level, so every oligarch has nonzero domestic
  capture.

4.4 RELATIONSHIPS: goodwill on every relationship (Relations; SYMMETRIC)
  G[a,b]  oligarch <-> oligarch, O x O, symmetric, zero diagonal, [-1,1]
          (slide 4: "alliance goodwill arises from inter-oligarchic
          interaction, both internationally and domestically")
  S[o,c]  state <-> oligarch, one value per relationship INCLUDING the home
          country, O x C, [-1,1] (slide 4: "state-oligarch goodwill, per
          pair")
  Both revert toward initial attitudes G0, S0.

  Initialization (own formulas):
    S0 = home_bonus*home + s_scale*(align - mean(align))
         - foreign_stigma*foreign
         align = cosine(oligarch preferences, country payoff_profile)
    G0 = overlap_sign*init_overlap_coef*(cosine(pref_a,pref_b) - mean)
         + same_country_bonus*co_resident ; symmetrized, clipped
    overlap_sign: -1 = same-industry overlap breeds RIVALRY ("collusion"
    is +1 = AFFINITY). Slide 6 calls these -1 (rivalry) / +1 (collusion).
    It enters BOTH initialization and dynamics.

  Dynamics (as implemented; 5 shared parameters: gw_decay, lam_oo, lam_inv,
  lam_cap, sigma_gw):
    f = position shares; Fc = f summed over industries (country shares)
    copresence = Fc Fc^T ; ovl = same (country, industry) overlap ;
    joint = copresence - ovl (same country, different industry)
    dG = gw_decay*(G0 - G) + lam_oo*joint + overlap_sign*lam_oo*ovl
         + sigma_gw*eps_oo                      (symmetric shocks)
    dS = gw_decay*(S0 - S) + lam_inv*tanh(positions_oc/a_ref)
         - lam_cap*(captured share of output) + sigma_gw*eps_os
    The earlier "halo" (vouching by liked locals) and separate per-matrix
    decay/lambda parameters were DROPPED to trim parameters; halo is a
    future extension, not part of v1.

  Effects:
    - capture effectiveness x clip(1 + zeta_cap*S, 0.2, inf)
    - capture effectiveness x clip(1 + eta*sum_b G_ab*presence_bc, 0.3, 2)
      (signed: rival presence hurts, partner presence helps)
    - backlash weight of an oligarch's capture x clip(1 - zeta_bl*S, 0.1,
      inf) x foreignness factor (1 + foreign_backlash_mult)
    - seizure on collapse x (1 - zeta_seize*max(S,0))
    - deployment attractiveness + goodwill_pull*(S + tanh(partner presence))

  Interpretation of S [OPEN, confirm]: S is the POLITY'S standing toward the
  oligarch (legitimacy), not the regime's favor. That is why higher S
  reduces seizure and backlash. If S means regime favor, those effects
  would flip or need rethinking.

4.5 CIVIL / RULING ASYMMETRY (own design; revised C6)   [DEPARTURE from slide 6: civil_cost_mult, see 13.6]
  CIVIL is the NEUTRAL baseline. RULING differs only through HOME ENTANGLEMENT, via ruling_home_mult = 1.5
  [SLIDES 6]:
    (a) capture effectiveness x1.5 at own home (cheaper domestic capture);
    (b) backlash weight x1.5 for capture at own home (state control more visible/attributable);
    (c) seizure fraction x1.5 (clipped to 1) if their OWN home country collapses (entangled with the fallen
        regime); also enters expected seizure in deployment.
  Abroad, both types follow IDENTICAL rules.
  civil_cost_mult (slide 6: 1.3, legal-defense/lobbying/intermediary running-cost multiple on civil
  positions) is 1.0 in the main design. Reasons: it is an own assumption with no source (Winters gives ruling
  oligarchs no cost advantage abroad; state power does not travel); it made foreign LEVELS differ by type by
  construction (8.2, d = 1.09); and it mechanically drove S (10-seed check at 1.3: civil exit ~23% vs ruling
  ~5% in the main block, but 8.8% vs 7.5% in the type-blind block). Kept as a parameter and run at 1.3 as an
  OFAT arm (run_design block "civil13").
  Slide 9 stylized fact, delivered by (c): after a nation falls, local ruling oligarchs lose more than local
  civil ones.
  CONSEQUENCE FOR P: with type-symmetric foreign rules, similar E-slopes are partly expected by design. A
  passing TOST shows that home-side type effects do not distort the E-slope; it does NOT show that type is
  irrelevant abroad. State as a scope condition. The type-blind block (ruling_home_mult = 1.0; null
  calibration, 5.2) still checks the pipeline: E x type slopes must be equal there.

4.7 STOCHASTICITY

  for G). Noise is not applied to accounting identities. Replication r uses
  the same seed across conditions (paired comparisons).

6. MEASURES AND ANALYSIS PLAN [SLIDES 7-8]
------------------------------------------
Unit of analysis: oligarch within run (country as a nested grouping).
Everything below is computed from per-tick logs (Section 10, item 4).

6.1 Network embeddedness E_i [AGREED; implemented in World.embeddedness]
  Per tick, from end-of-tick positions and current G. Presence p_ic = tanh(position_ic / a_ref).
    E_foreign_i = sum_j G_ij * ( sum over countries c FOREIGN to i of p_ic * p_jc ) / (O-1)    <- PRIMARY
  Partners of ANY home count (locals included). Robustness: E_all (all countries); E_pos / E_neg (the
  positive / negative-G parts; E_foreign = E_pos + E_neg). Denominator fixed at O-1. Exited agents hold
  no positions (p = 0), so they drop out of everyone's E automatically.
  E = 0 conflates "no ties" with exactly offsetting ties: CONTROL FOR FOREIGN PRESENCE in the analysis.
  Lag: E is measured over the EMBEDDING window (20-50% of ticks), outcomes over the OUTCOME window
  (50-100%), so E is not mechanically contained in the outcome. Mask with `active`; E = 0 for inactive agents.
  State goodwill (S_home, S_foreign_mean, S_foreign_pw) is logged and used as covariate / robustness.

6.2 Dependent variables for P
  - FOREIGN CAPTURE RATE [AGREED]: per-tick foreign share = foreign / (foreign + domestic capture gained),
    capture gained = extraction + capture rent. DV = MEAN over the outcome window; MEDIAN = robustness.
    Robustness alternative: foreign-only rate per unit average foreign capital (the share is diluted by
    ruling_home_mult's domestic inflation; the rate is not). The slide-8 mock y-axis (~5-20) is not on a
    share scale; regenerate the real figure with the chosen scale.
  - HAVOC [AGREED; RESOLVED: abuse-based]: the oligarch's Tullock effort share of the pool abuse damage
    (abuse x prior health x full-stock value V), split into foreign_havoc / domestic_havoc; same mean /
    median and share / rate treatments as capture. abuse = abuse_coef*max(0, h - h_star), h = 1 - exp(-qX).
    abuse_coef is a global scalar, so havoc is emergent, not a trait. The old backlash-load contribution
    survives only as a diagnostic (foreign_load, domestic_load).

6.3 Exit and asset loss for S
  - EXIT [AGREED]: ACTIVE capital (liquid + positions; OFFSHORE EXCLUDED) below exit_floor_frac (0.40) x
    INITIAL active capital for exit_window (10) consecutive ticks. Absorbing; exit_tick recorded.
    Floor and window are placeholders: confirm against the exit-tick distribution before fixing windows.
  - ON EXIT [IMPLEMENTED]: positions are LIQUIDATED at fire_sale_loss (30%); proceeds + liquid capital go
    offshore (exit_transfer; not flight); the discount is destroyed (exit_liq_loss); active = False; the
    agent skips all behavior, including offshore return (exited agents' offshore stops earning). Goodwill
    rows of exited agents keep drifting but have no effect (presence 0). RECORD: this replaces the earlier
    exit write-off. Proceeds are NOT redistributed to the state, rivals or population (scope condition).
  - LOSS ACCOUNTING (value DESTROYED; flight is a transfer): (1) collapse seizure; (2) resident liquid hit
    at home collapse; (3) forced (insolvency) liquidation loss; (4) voluntary divestment loss.
    S headline covariate = (1)+(2) over initial active capital; (3) = robustness; (4) EXCLUDED as circular.
    cum_debt_forgiven was REMOVED: the limited-liability clamp is original M0 behavior, untracked, and never
    binds at current parameters (the earlier "406 events" were float dust).
  - Anti-tautology: exit is wealth-based, so S is partly mechanical. Nested models start from initial
    active capital (plus gamma, overlap) and test whether the seized fraction adds beyond it.

6.4 Statistics  [analysis plan: commit BEFORE looking at real run output]
  P (capture and havoc, separately): linear mixed models, random intercepts for run and country-within-run,
    covariates E, type, overlap_sign, initial wealth and foreign presence. E x type similarity is judged by
    an equivalence test (TOST); margin ~20-25% of the pooled slope, with 10% and 30% as sensitivity, FIXED
    BEFORE real runs. E^2 x type tests curvature; per-type slope positivity is reported. The type-blind
    block (5.2) is the null calibration: E x type slopes must be equal when ruling_home_mult = 1.0 (no type asymmetry).
    Report who drops out by type (survivorship) and partial-window robustness.
  Disclosure: E -> capture is partly BUILT IN via eta (partner presence in the capture multiplier). P is
    therefore the net strength of that channel against backlash, seizure and depletion, plus type
    similarity. Run an eta = 0 ablation (expected to collapse the E -> capture slope).
  S: PERSON-PERIOD clustered logit (cluster on run; Liang & Zeger 1986), covariates lagged 1 tick. Nested:
    M0 (initial active capital, gamma, overlap) -> + seized fraction -> + E -> + type. Report odds ratios,
    delta-AUC / BIC, marginal R2 (Nakagawa & Schielzeth), drop-one-from-full. With ~20,000 rows p-values
    are uninformative: lead with effect sizes.
  Never tune toward P or S outcomes (5.5). Sandbox lacks statsmodels / pyarrow: models run locally.
  OFAT sensitivity (Section 7): slide-9 constants capture_rent, civil_cost_mult, ruling_home_mult,
    zeta_seize, PLUS eta, h_star, abuse_coef, w_scar, exit_floor_frac (0.35/0.40/0.45).
